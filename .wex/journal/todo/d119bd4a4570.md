# Page tunnels : refaire l'illustration avec les composants DS

Opened: 2026-09-24
Updated: 2026-09-24
Author: agent:main (design-system)

## Pourquoi

`assets/pages/design_system/tunnels/index.html.twig` montre l'arbre des curseurs du tunnel
de démo. La page reste en l'état tant que le package se construit, parce qu'elle prouve que
le moteur est branché. Sa représentation est à refaire ensuite.

## Ce qui ne va pas

- La profondeur est simulée par une `<ul>` à plat et `style="margin-left: …rem"` dans
  `.content`, ce qui donne des puces de prose en escalier.
- Il y a un `<h1>` écrit à la main, alors que le layout affiche déjà le titre de la page.
- La phrase d'intro est en dur dans le Twig : `index.en.yml` ne contient que le titre.
- Les options sont affichées en JSON brut (`json_encode`).

## À faire

- Utiliser `@WexampleSymfonyDesignSystemBundle/components/tree` (items `label`, `icon`,
  `depth`, `children`) : `buildTreeLines` doit imbriquer les étapes au lieu de les aplatir.
- Envisager un flowchart mermaid (symfony-content) : un tunnel est un graphe, où la même
  étape revient une fois par chemin.
- Utiliser le composant DS `stepper` pour situer le visiteur dans un tunnel parcouru.
- Traduire les textes et afficher les options avec `properties`.
